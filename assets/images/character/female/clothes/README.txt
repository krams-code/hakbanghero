Female clothing, one PNG per body size (all 286x512, transparent).
Drawn 1:1 on top of female/body_<bodyType>.png - the app never scales them.

Name = <outfit>_<bodyType>.png   (bodyType = underweight | normal | overweight | obese)

Starter set (white tank top + shorts), 4 files needed:
  starter_set_underweight.png
  starter_set_normal.png
  starter_set_overweight.png
  starter_set_obese.png

Until a file exists, the app falls back to the old one-size outfit.
Future outfits follow the same rule, e.g. obsidian_set_obese.png.
